Connect with a token

Claude Code, Cursor, Windsurf, scripts
Create a token, then register the MCP server with it. The agent authenticates with Authorization: Bearer ….
claude mcp add --transport http switchboard {{.MCPURL}} \
  --header "Authorization: Bearer <token>"
Or from the CLI in one step: switchboard mcp add claude-code. Install the serving skill with switchboard skill install so the agent knows the loop.

Connect with OAuth

Claude Desktop/claude.ai connectors, VS Code, MCP Inspector
Clients that support OAuth discover this server automatically. Add the MCP URL as a custom connector; you will be asked to sign in here and approve the client. Tokens issued this way appear below.
{{.MCPURL}}
Metadata: authorization server · protected resource. Hosted clients (claude.ai) need a public URL — set it in Settings when using a tunnel.
